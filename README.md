# Rakodástervező 3D 0.5 – GitHub Pages

A weboldal indítófájlja a gyökérkönyvtárban található `index.html`; a `ldm_modul.js` ugyanitt szükséges.

A `fuvardij_kapcsolat/fuvardij4_adapter.py` **nem fut** GitHub Pages-en, mert az csak statikus HTML/CSS/JavaScript oldalt szolgál ki. A 3D rakodási tervező és az LDM-mutatók böngészőben működnek; az árajánlat-adatcsomag letölthető, a Python adaptert külön gépen kell használni.

Telepítés: a ZIP tartalmát (nem magát a ZIP-et) töltse fel a GitHub repository gyökerébe, majd Settings > Pages > Deploy from a branch > main > / (root).

A program rakodási tervezéshez és díjkalkuláció-előkészítéshez készült, nem igazol rakományrögzítést vagy menetbiztonságot.
